How the implied value is scored (model radar-2)

Implied value = TVL × 0.30 × growth × maturity, capped at 0.75 × TVL. Growth is the 7-day TVL change clamped to −80%..+200%: rises count at 0.6, falls count at 1.0, so a shrinking protocol is punished harder than a growing one is rewarded; the factor is clamped to 0.35..2.0. Maturity is 0.60 + 0.40 × log(1 + age / 120 days) / log(1 + 1460 / 120 days): a protocol that has run years with no token has proven it can survive without one, with diminishing returns per extra year. No protocol name is ever special-cased — the same function scores every row, from TVL, growth and age alone.

A protocol “records no token” when the snapshot carries no market cap, CoinGecko id or symbol for it. That is the snapshot’s record, not proof it has none. Protocols whose token already trades are listed separately below, at the market’s own market cap, and never ranked on this board.
